# knob-demos

Knob-control demos for Koala Sampler. Static site (deploy on Vercel as-is, no build step).

- `index.html` – the demo; behaviours are listed in the `behaviours` array, one per numbered page.
- `assets/bg.jpg` – screenshot with the pitch knob painted out.
- `previews/` – min/max screenshots and an animation clip for page 1.
